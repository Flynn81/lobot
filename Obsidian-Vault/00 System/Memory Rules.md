# Memory Rules

- Store durable knowledge, not transcripts.
- Search before creating a new canonical note.
- Prefer atomic notes and `[[wikilinks]]`.
- Record provenance and dates.
- Distinguish explicit user decisions, sourced research, and assistant inference.
- Preserve contradictions until resolved.
- Do not store credentials or secrets.
- Keep `90 Inbox` temporary; consolidate useful items into canonical notes.
