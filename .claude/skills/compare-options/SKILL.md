---
name: compare-options
description: Compare two or more products, technologies, strategies, vendors, jobs, or other alternatives against explicit criteria. Use when the user wants a practical side-by-side comparison rather than broad research.
argument-hint: [options and goal]
---

Compare the options described here:

$ARGUMENTS

First infer the user's goal and constraints from available context. Then:
1. Establish 4-8 criteria that materially affect the decision.
2. Mark any criterion that is a hard requirement.
3. Compare only meaningful differences; do not pad the analysis with trivia.
4. Explain tradeoffs and edge cases.
5. Recommend the best overall option plus any option that wins for a distinct scenario.

If key facts may have changed, verify them before comparing.
